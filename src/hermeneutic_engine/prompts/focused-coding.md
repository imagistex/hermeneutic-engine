Method: focused coding with a fixed codebook.

You will receive a codebook and a batch of units. Each unit has an ID, some context and its text. Apply the codebook to each unit.

- Apply a code only where its definition fits what the unit says or does. Use `apply_when` and `do_not_apply_when` to decide between neighbouring codes.
- A unit may take several codes, one, or none.
- For every code you apply, quote the words in the unit that warrant it. Quote exactly.
- Do not stretch a code to cover something it was not written for. If a unit does something the codebook has no code for, leave that uncoded and report it in `unfit`: quote the passage, say what is being done, and suggest a name.
- Use `note` only when the fit is doubtful, when two codes compete, or when a word may carry more than one sense (begin that note with `loaded:`). Leave it empty otherwise.

In `batch_memo`, write two to four sentences on where the codebook fit poorly in this batch.
